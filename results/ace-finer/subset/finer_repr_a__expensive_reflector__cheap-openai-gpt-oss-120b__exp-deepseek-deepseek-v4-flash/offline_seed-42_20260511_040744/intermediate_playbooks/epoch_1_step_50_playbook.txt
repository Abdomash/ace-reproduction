[err-00001] helpful=0 harmful=0 :: Do not default to the generic SharePrice tag for prices associated with convertible debt instruments; instead use the specific tag DebtInstrumentConvertibleConversionPrice1 for conversion prices.

## PROBLEM-SOLVING HEURISTICS

[ph-00017] helpful=0 harmful=0 :: When tagging fair‑value amounts, first identify the instrument type; if it is a debt instrument, then check whether it is classified as long‑term. Choose the most specific tag that combines both the measurement concept (fair value) and the instrument classification (e.g., LongTermDebtFairValue). Only fall back to DebtInstrumentFairValue if no long‑term‑specific tag exists.
[ph-00020] helpful=0 harmful=0 :: If a sentence describes a parent acquiring a majority of another entity’s shares and mentions a change in control, prioritize acquisition‑related ownership tags (EquityMethodInvestmentOwnershipPercentage, BusinessAcquisitionPercentageOfVotingInterestsAcquired) over any minority‑interest tags.
[ph-00029] helpful=0 harmful=0 :: When a sentence mentions a monetary amount related to letters of credit, first determine whether the amount is a capacity/limit or an outstanding balance. Use LineOfCreditFacilityMaximumBorrowingCapacity for capacity statements (e.g., 'up to $X million', 'commitments may be used', 'total size of letter of credit facilities') and LettersOfCreditOutstandingAmount only when the text explicitly says the amount is outstanding.
[ph-00034] helpful=0 harmful=0 :: helpful=0 harmful=0 :: When tagging revenue amounts, first determine if the revenue is recognized under ASC 606 (i.e., from contracts with customers). If so, select RevenueFromContractWithCustomerExcludingAssessedTax before considering the generic Revenues tag.
[ph-00036] helpful=0 harmful=0 :: When a sentence describes a discount amount for a debt instrument, first determine whether the discount is characterized as amortized or unamortized. Use DebtInstrumentUnamortizedDiscount for unamortized discounts and, if a distinct amortized‑discount tag exists, use that for amortized discounts; only fall back to the generic DebtInstrumentDiscount when no distinction is provided.
[ph-00041] helpful=0 harmful=0 :: When multiple tags could apply, prioritize the most specific descendant tag in the taxonomy that directly references the described concept. Compare tag specificity by length and hierarchy (e.g., tags ending with 'PeriodForRecognition' are more specific than generic 'RecognitionPeriod'), and always select the longest, most detailed tag that matches the context.
[ph-00043] helpful=0 harmful=0 :: When evaluating acquisition‑related monetary amounts, first determine whether the amount represents total consideration (including equity, contingent consideration, and cash) or the net cash paid. If the sentence references cash, cash outflow, or net cash used to acquire the business, select PaymentsToAcquireBusinessesNetOfCashAcquired; otherwise use BusinessCombinationConsiderationTransferred1.
[ph-00046] helpful=0 harmful=0 :: When multiple tags could apply, first verify that the text contains explicit qualifiers (e.g., 'operating lease', 'net of sublease income') that match the specific descendant tag's definition; if such qualifiers are absent, default to the parent (broader) tag.
[ph-00048] helpful=0 harmful=0 :: [ph-00052] helpful=0 harmful=0 :: When a sentence lists one or more monetary amounts associated with "amortization of intangible assets", treat each amount independently and assign the AmortizationOfIntangibleAssets tag to every amount mentioned, even if they appear in a single sentence or list.
[ph-00051] helpful=0 harmful=0 :: When a sentence mentions employer contributions to "the plans" without specifying the plan type, first scan for defined‑benefit indicators (e.g., "pension", "benefit obligation", "defined‑benefit plan"). If none are found, default to the tag DefinedContributionPlanCostRecognized, which captures the expense recognition for defined‑contribution plan contributions.
[ph-00054] helpful=0 harmful=0 :: When evaluating acquisition‑related monetary amounts, first check for qualifiers like 'net of cash acquired' or 'cash acquired'. If such qualifiers are absent and the text describes a cash payment (e.g., 'all‑cash transaction', 'paid $X in cash'), select PaymentsToAcquireBusinessesGross rather than PaymentsToAcquireBusinessesNetOfCashAcquired.
[ph-00057] helpful=0 harmful=0 :: When a sentence mentions an effective tax rate and explicitly cites the statutory tax rate (e.g., "35% federal statutory rate"), prioritize tags that include 'Reconciliation' and 'Statutory' over plain effective‑rate tags.
[ph-00058] helpful=0 harmful=0 :: When a sentence mentions monetary amounts described as "charges" recorded in SG&A, Cost of products sold, or similar operating expense categories, interpret these as RestructuringCharges unless the text explicitly references lease terms, sublease income, or rental language. Use the RestructuringCharges tag instead of OperatingLeasesRentExpenseNet or generic lease expense tags.
[ph-00059] helpful=0 harmful=0 :: If the wording indicates the company "received" value in a transaction (e.g., "value received in the transaction", "consideration received", "proceeds from the disposal"), map the amount to DisposalGroupIncludingDiscontinuedOperationConsideration. Conversely, when the text states the company "paid" or "transferred" value (e.g., "consideration paid", "value transferred to acquire"), use BusinessCombinationConsiderationTransferred1 or PaymentsToAcquireBusinesses tags as appropriate.
[ph-00062] helpful=0 harmful=0 :: When a sentence mentions a quantity of share‑based awards (e.g., RSUs, options) granted or scheduled to vest, first look for tags that end with 'GrantsInPeriod' (count tags). Only consider fair‑value tags (e.g., WeightedAverageGrantDateFairValue, VestedInPeriodTotalFairValue) if the text explicitly references a monetary value per award.
[ph-00065] helpful=0 harmful=0 :: When a sentence reports the number of business segments (e.g., 'We operate in two reportable business segments'), always map the quantity to the NumberOfOperatingSegments tag. Prioritize the taxonomy definition over surface‑level wording; verify the tag list for the authoritative segment‑count tag before considering any adjective‑based variants.
[ph-00074] helpful=0 harmful=0 :: When a sentence mentions multiple time periods for a share‑based award, first determine the concept: if the period refers to when the award becomes exercisable, use a 'VestingPeriod' tag; if it refers to the overall life or expiry of the award, use an 'ExpirationPeriod' tag. Apply each tag separately to the corresponding numeric value.
[ph-00082] helpful=0 harmful=0 :: When your reasoning leads to a tag that exactly matches the described financial concept and no alternative tag fits better, treat this as a validation point; avoid unnecessary re‑evaluation that could introduce error.
[ph-00086] helpful=0 harmful=0 :: When a percentage ownership is reported, first determine the level of control: if the percentage is >50% and the text mentions a remaining minority interest, use MinorityInterestOwnershipPercentageByParent to report the parent's ownership in a subsidiary with noncontrolling interest. If the percentage falls between 20% and 50% (significant influence) and no minority interest is highlighted, use EquityMethodInvestmentOwnershipPercentage.
[ph-00087] helpful=0 harmful=0 :: When the sentence describes shares, equity interests, or other securities issued as consideration in a business combination, first scan the provided tag list for any tag containing the prefix 'BusinessAcquisition'. If such a tag exists (e.g., BusinessAcquisitionEquityInterestsIssuedOrIssuableNumberOfSharesIssued), select it before considering generic issuance tags like StockIssuedDuringPeriodSharesNewIssues.
[ph-00089] helpful=0 harmful=0 :: When a sentence mentions "debt obligations" (or similar phrasing) within a balance‑sheet or year‑end footnote context and does not separately disclose a current portion, infer that the amount refers to long‑term debt and select the LongTermDebtFairValue tag rather than the generic DebtInstrumentFairValue.
[ph-00092] helpful=0 harmful=0 :: When a sentence mentions both "deferred stock units" (or RSUs) and a monetary amount described as "fair value per unit" (or similar), prioritize the WeightedAverageGrantDateFairValue tag over count‑based tags such as GrantsInPeriod, because the presence of a per‑unit fair‑value figure signals a valuation rather than a quantity.
[ph-00093] helpful=0 harmful=0 :: When a sentence states the useful life of a finite‑lived intangible asset that is *not* described as acquired (e.g., "the patent has a useful life of 17 years"), select the generic FiniteLivedIntangibleAssetUsefulLife tag. Only switch to AcquiredFiniteLivedIntangibleAssetsWeightedAverageUsefulLife when the text explicitly mentions acquisition.
[ph-00094] helpful=0 harmful=0 :: When a monetary amount is identified as depreciation expense (e.g., "depreciation expense of $11,096"), map the amount to the Depreciation tag. Ensure the context is an expense line item, not a depreciation method or schedule discussion.
[ph-00095] helpful=0 harmful=0 :: When a sentence provides a numeric value together with a clear qualifier (e.g., "1.5 billion shares of common stock", "par value of $0.0001 per share"), directly map the value to the most specific US GAAP tag that reflects that qualifier (e.g., CommonStockSharesAuthorized, CommonStockParOrStatedValuePerShare) without seeking alternative interpretations.
[ph-00100] helpful=0 harmful=0 :: When a sentence mentions a monetary amount tied to "intrinsic value of options exercised", prioritize the intrinsic‑value‑specific tag (e.g., ShareBasedCompensationArrangementByShareBasedPaymentAwardOptionsExercisedIntrinsicValueTotal) over generic option‑related tags. [ph-00110] helpful=0 harmful=0 :: When evaluating monetary amounts related to a debt instrument, first determine if the amount represents the principal (face) amount. Only if the amount is an interest rate, discount, or fair‑value measurement should you consider tags such as DebtInstrumentInterestRateStatedPercentage, DebtInstrumentUnamortizedDiscount, or DebtInstrumentFairValue. This hierarchy ensures the most specific principal tag is chosen before other debt‑instrument tags.
[ph-00112] helpful=0 harmful=0 :: When a sentence mentions a tax benefit derived from operating loss carryforwards, prioritize the OperatingLossCarryforwards tag over generic tax‑benefit or income‑tax expense tags. Use the specific tag whenever the phrase "operating loss carryforwards" (or a close variant) is present.
[ph-00118] helpful=0 harmful=0 :: When a sentence reports a parent’s ownership percentage in a partnership, limited partnership, or joint venture and does not mention equity‑method accounting, select MinorityInterestOwnershipPercentageByParent. Only consider EquityMethodInvestmentOwnershipPercentage if the disclosure explicitly references equity‑method accounting.
[ph-00120] helpful=0 harmful=0 :: When a passage mentions multiple amounts for the same credit facility, treat the first amount (often introduced with past or present tense verbs like "had" or "has") as the current borrowing capacity, and any subsequent amount introduced with language such as "may increase to", "up to", "maximum", or "can be increased" as the maximum borrowing capacity. Apply LineOfCreditFacilityCurrentBorrowingCapacity to the former and LineOfCreditFacilityMaximumBorrowingCapacity to the latter.
