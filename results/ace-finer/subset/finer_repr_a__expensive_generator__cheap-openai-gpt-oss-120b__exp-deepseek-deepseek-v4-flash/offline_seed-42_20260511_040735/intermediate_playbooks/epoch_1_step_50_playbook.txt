## COMMON MISTAKES TO AVOID

[err-00003] helpful=0 harmful=0 :: Do not default to generic monetary tags (e.g., MonetaryAmount) when a more precise tag exists. Selecting the specific tag improves alignment with the US GAAP taxonomy and reduces errors.
[err-00006] helpful=0 harmful=0 :: Do not assign generic MonetaryAmount or other non‑share tags to share count numbers; always use the specific share‑related tags (e.g., SharesAuthorizedForFutureAwards, SharesRepurchased) to capture the transaction correctly.
[err-00009] helpful=0 harmful=0 :: Do not assign generic tags like DebtInstrumentInterestRateStatedPercentage or MonetaryAmount to basis spreads or commitment fees. Using a generic interest‑rate tag for a basis spread or a generic fee tag for a commitment fee leads to mis‑classification; always choose the dedicated tag that reflects the exact financial concept.
[err-00013] helpful=0 harmful=0 :: Do not assign generic MonetaryAmount or generic expense tags to acquisition‑related costs; always use BusinessCombinationAcquisitionRelatedCosts when the context is a business combination. Likewise, avoid generic line‑of‑credit tags for capacity figures—use LineOfCreditFacilityMaximumBorrowingCapacity for the overall limit.
[err-00015] helpful=1 harmful=0 :: Do not assume that shares issued to directors for service constitute share‑based compensation. If the tag list includes StockIssuedDuringPeriodSharesNewIssues, that tag should be used for any share‑issuance quantity, even when the purpose is compensation, purchase, or other consideration.
[err-00019] helpful=0 harmful=0 :: Do not assign the generic DebtInstrumentFairValue tag to senior notes or other long‑term debt instruments when LongTermDebtFairValue is available; using the specific tag prevents mis‑classification.
[err-00021] helpful=0 harmful=0 :: Do not apply BusinessAcquisitionPercentageOfVotingInterestsAcquired to percentages that describe ownership of the reporting entity itself; the correct tag for change‑in‑control ownership percentages is EquityMethodInvestmentOwnershipPercentage.
[err-00025] helpful=0 harmful=0 :: Do not return an empty response or fewer tags than requested. For questions that ask for a tag per numeric entity, always produce exactly that many tags, in the same order as the entities, separated by commas, even if the same tag repeats.
[err-00031] helpful=0 harmful=0 :: Never return placeholder text such as 'No final answer found' or omit the answer; always produce the exact number of tags requested, formatted as a comma‑separated list.
[err-00036] helpful=0 harmful=0 :: Do not select IncomeTaxExpenseBenefit merely because the word "tax" appears. Verify whether the context describes a loss contingency estimate (e.g., "incremental tax liability"); if so, use LossContingencyEstimateOfPossibleLoss instead.
[err-00037] helpful=0 harmful=0 :: Do not confuse NumberOfReportableSegments with NumberOfOperatingSegments. When the text mentions both "reportable" and "operating" segments, ensure you identify which segment count is being reported and choose the corresponding tag.
[err-00041] helpful=0 harmful=0 :: helpful=0 harmful=0 :: Do not map phrases like "not to exceed $X million" for letters of credit to LettersOfCreditOutstandingAmount. Such phrasing indicates a maximum commitment, not an outstanding balance; the correct tag is LineOfCreditFacilityMaximumBorrowingCapacity.
[err-00044] helpful=0 harmful=0 :: Do not select the more specific tag InterestExpenseDebt for interest expense amounts when the context does not explicitly link the expense to a debt instrument; the correct tag in such cases is the generic InterestExpense.
