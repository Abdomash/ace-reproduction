```python
shares = {}

    line = line.strip()
    if not line or not any(sep in line for sep in ['=>', ':', '-']):
        continue
    # Find the separator used
    for sep in ['=>', ':', '-']:
        if sep in line:
            parts = line.split(sep, 1)
            break
    name = parts[0].lstrip('-').strip()
    amount_str = parts[1].replace('$', '').strip()
    try:
        amount = float(amount_str)
    except ValueError:
        continue
    shares[name] = amount
```

page_index = 0
while True:
    page = apis.<app>.show_<endpoint>(access_token=token, page_index=page_index, page_limit=20)
    if not page:
        break
    # process items in page

[code-00034] CSV building without external modules:
```python
lines = ["Title,Artists"]
for song in songs:
    title = song["title"].replace('"', '""')
    artists = "|".join(a.replace('"', '""') for a in song["artists"])
    # wrap fields containing commas in double quotes
    if "," in title:
        title = f'"{title}"'
    if "," in artists:
        artists = f'"{artists}"'
    lines.append(f"{title},{artists}")
csv_content = "\n".join(lines)
```

Many tasks do not require an answer, so in those cases, just call apis.supervisor.complete_task() i.e. do not pass any argument.
[misc-00011] Always inspect the API response schema via `show_api_doc` to identify which fields contain the required data (e.g., `song_ids` in playlist library, `like_count` in song details). This helps avoid extra API calls and clarifies data extraction steps.
