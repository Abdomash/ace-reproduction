[shr-00092] When parsing Simple Note content for expense shares, use a tolerant pattern that handles different separators (e.g., '=>', ':', '-', or any whitespace) and strips leading dashes and spaces. Example:
```python
shares = {}
for line in content.splitlines():
    line = line.strip()
    if not line or not any(sep in line for sep in ['=>', ':', '-']):
        continue
    # Find the separator used
    for sep in ['=>', ':', '-']:
        if sep in line:
            parts = line.split(sep, 1)
            break
    name = parts[0].lstrip('-').strip()
    amount_str = parts[1].replace('$', '').strip()
    try:
        amount = float(amount_str)
    except ValueError:
        continue
    shares[name] = amount
```
